Thiết lập lượt cào

Chọn từ 81 thành phố quốc tế có sẵn hoặc dán URL tùy biến.

Hoặc nhập từ file ?Không cần định dạng đặc biệt. Tool quét mọi ô trong file và nhặt ra hotelId (số 4–12 chữ số) hoặc URL trang khách sạn Trip.com; có dòng tiêu đề hay cột khác cũng không sao.

• .txt: mỗi dòng một ID/URL
• .csv / .tsv: bất kỳ cột nào, phân cách , ; tab đều được (UTF-8 hoặc Excel)
• .xlsx: quét mọi sheet, mọi ô; ô số dạng 1.97E+06 vẫn đọc đúng

Sau khi đọc, các ID được đổ vào ô dán bên trái để anh kiểm tra/sửa trước khi cào. Tối đa 5.000 khách sạn một lần, file ≤ 25 MB.
